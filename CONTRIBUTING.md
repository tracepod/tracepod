# Contributing to Tracepod

## Prerequisites

Most of Tracepod — the hardener, CLI, manifest library — builds and tests on macOS or Linux
with just Go 1.26+:

```bash
CGO_ENABLED=0 go build ./...
go test ./...
```

The **sensor** requires a Linux kernel (6.8+) with eBPF support, clang-18, and bpftool.
For macOS development, use a Lima VM (see below). Linux-specific tests also run automatically
on every pull request via GitHub Actions.

## Setting up the eBPF dev environment (Lima VM)

Lima creates a lightweight Ubuntu 24.04 VM with the full BPF toolchain installed.

**Install Lima:**
```bash
brew install lima
```

**Create the VM** using the provided config:

```bash
limactl create --name ebpf-dev infra/lima/ebpf-dev.yaml
limactl start ebpf-dev
```

**Open a shell:**
```bash
limactl shell ebpf-dev
```

The `~` directory is mounted read-write into the VM, so your local checkout is available at
the same path inside the VM.

**Verify the environment:**
```bash
# Inside the VM
uname -r              # should be 6.8.x
clang --version       # should be 18+
go version            # should be 1.26
sudo bpftool prog list
```

## Building inside the VM

```bash
# Generate BPF objects from the running kernel's BTF
make generate

# Build sensor binary
CGO_ENABLED=0 go build -o bin/sensor ./cmd/sensor/

# Run all tests (Linux-native)
go test ./...
```

## Running tests

```bash
# macOS or Linux (Linux-constrained tests are skipped on macOS)
go test ./...

# Linux only: full suite including container/cgroup tests
go test -v ./internal/container/...
go test -v ./internal/ringbuf/...
```

## Code structure

```
cmd/
  sensor/      eBPF sensor binary (Linux only)
  harden/      Image hardener CLI
  tracepod/    Controller API client CLI

manifest/      Manifest schema, aggregation, confidence scoring, denylist
hardener/      OCI image builder, ELF resolver, SBOM, keychain

internal/
  probe/       BPF program objects (generated by bpf2go)
  ringbuf/     BPF ring buffer consumer
  container/   Cgroup ID resolution, NRI integration
  sensor/      K8s workload metadata, event posting
```

## Commit conventions

Use [Conventional Commits](https://www.conventionalcommits.org/):

```
feat(manifest): add observation source to aggregator
fix(hardener): resolve rpath in ELF deps
docs: update architecture overview
```
